Cardbook

The daily sales book for branch pharmacies — replaces paper, catches mistakes the same day.

If you run a branch: sell fast, count 2 items on the shelf, close the day in minutes.

If you run HQ: see every branch today, without waiting for month-end.

How today works — 3 steps, ~5 minutes

1. Sell — pick drug, tap +/-, confirm. Price is filled for you.
2. Count 2 items — we pick 2 drugs, you count what's on the shelf.
3. Close — see green (done) or what to explain, then close. HQ sees it.
